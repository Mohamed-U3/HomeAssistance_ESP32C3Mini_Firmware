◆ ensureWifiConnected()

void ensureWifiConnected ( WifiTickCallback onTick)

Ensure Wi-Fi connectivity at boot using a resilient search-and-portal cycle.

Searches for the saved SSID for 2 minutes; if unreachable (or none saved), opens the SoftAP portal for 3 minutes, then loops back to retry the saved SSID if timed out.

Parameters
onTickOptional callback invoked during wait/portal loops.
